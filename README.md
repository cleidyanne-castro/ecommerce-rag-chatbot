# E-commerce RAG Chatbot

Privacy-safe e-commerce assistant using RAG, Shopify, AWS and public e-commerce datasets.

## Project goals

- Answer technical questions about products
- Recommend products based on customer needs
- Compare products
- Check order status
- Display tracking information
- Integrate with Shopify
- Use RAG for product knowledge and policies
- Use APIs for real-time transactional data

## Initial datasets

- Olist Brazilian E-Commerce Dataset
- Amazon Reviews 2023

## Planned stack

- Databricks
- SQL
- Python
- Pandas
- FastAPI
- LangChain
- Vector database
- Amazon Bedrock
- Shopify API
- Streamlit
